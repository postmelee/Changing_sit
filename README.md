# 자리 바꾸기 · Changing Sit

엑셀 명렬표를 불러와 교실 크기에 맞게 자리를 배치하는 웹 도구입니다. 칠판에 가까운 앞줄부터 채우는 일반 배치와, 지정한 두 학생을 나란히 앉히는 멘토·멘티 배치를 지원합니다.

**[자리 바꾸기 사용하기 →](https://postmelee.github.io/Changing_sit/)**

별도 설치나 회원가입 없이 사용할 수 있습니다. 명렬표는 브라우저 안에서만 처리하며 서버로 전송하지 않습니다.

## 웹에서 사용하기

1. [Changing Sit](https://postmelee.github.io/Changing_sit/)에서 **예시로 시작**을 누르거나 **엑셀 불러오기**로 명렬표를 선택합니다.
2. 왼쪽 **교실 설정**에서 가로·세로를 +/− 또는 숫자로 조절하고, 짝꿍형·개별형을 선택한 뒤 **배치 적용**을 누릅니다.
3. **자리 바꾸기** 또는 **천천히 공개**를 누릅니다. 지정한 짝을 유지하려면 아래의 엑셀 형식을 사용하고 **멘토·멘티 배치**를 누릅니다.
4. **시점 변환**으로 자리표의 방향을 바꿀 수 있습니다.
5. 사이드바 오른쪽 위의 작은 **‹ / ›** 버튼으로 명렬표·교실 설정을 접거나 펼칠 수 있습니다.
6. 상단 자리표 제목을 클릭해서 수정하고, **전체화면**으로 자리표를 크게 보여줄 수 있습니다. 버튼 또는 Esc로 돌아옵니다. 전체화면 API를 지원하지 않는 환경에서는 브라우저 안에서 확장됩니다.
7. 배치를 완료한 뒤 **PDF 저장 / 인쇄**를 누릅니다. 브라우저 인쇄 창에서 PDF 저장 또는 프린터를 선택합니다. 제목과 자리표만 A4 가로 한 장에 맞추는 전용 레이아웃을 사용하며, 인쇄 창에서 용지·배율을 변경하면 결과가 달라질 수 있습니다. 순차 공개 중에는 버튼이 비활성화됩니다.

멘토·멘티 버튼에 마우스를 올리거나 옆의 **?**를 누르면 짝 번호 작성법과 실행 조건에 대한 설명을 볼 수 있습니다. 키보드로도 설명을 확인하고 Esc로 닫을 수 있습니다.

파일은 브라우저 안에서만 읽으며 서버로 전송하거나 저장하지 않습니다. 새로고침하면 이름과 배치 결과가 사라집니다.

지원 형식은 `.xlsx`, `.xls`, UTF-8 `.csv`의 첫 번째 시트, 최대 144명·5MB입니다. 가장 명확한 형식은 아래와 같습니다.

| 번호 | 이름 |
|---|---|
| 1 | 학생01 |
| 2 | 학생02 |

[예시 엑셀 다운로드](docs/sample-roster.xlsx)

‘성명’, ‘학생명’, ‘Name’ 등의 열 제목, 제목 없는 이름 한 열, 번호+이름 형식도 지원합니다. 이름 열이 모호하면 열 제목을 ‘이름’으로 작성하도록 안내합니다. 동명이인은 각각 한 명으로 유지합니다.

교실 크기는 가로·세로 각각 1~12로 지정할 수 있습니다. 명렬표 인원보다 좌석이 부족하면 배치를 막고 좌석을 늘리도록 안내합니다. 배치 적용 시 기존 자리 결과는 비우지만 명렬표는 유지합니다. **자리 비우기**는 순차 공개도 중지합니다. 학생 순서는 무작위로 섞되, 칠판에 가까운 앞줄부터 왼쪽에서 오른쪽으로 채웁니다. 빈자리는 뒤쪽에만 남습니다. 시점을 뒤집어도 실제 칠판 기준 앞뒤는 유지됩니다.

## 실제 멘토·멘티 배치

엑셀 첫 시트에서 한 행에 한 학생을 작성하고 **짝 번호** 열을 추가합니다. 같은 번호를 가진 두 학생이 옆자리에 배치됩니다. 이름이 같아도 서로 다른 행은 각각 한 명으로 취급합니다.

| 번호 | 이름 | 짝 번호 |
|---|---|---|
| 1 | 가람 | 1 |
| 2 | 나래 | 1 |
| 3 | 다온 | 2 |
| 4 | 라온 | 2 |
| 5 | 마루 | |

- 같은 짝 번호는 정확히 두 명이어야 합니다. 번호 대신 A, B 등의 문자도 사용할 수 있습니다.
- 짝 번호가 빈 학생은 개별 배치합니다. 같은 번호가 한 명뿐이거나 세 명 이상이면 오류를 안내하며 기존 명렬표와 자리를 유지합니다.
- **짝 명렬표 예시 ↓**에서 38명·19쌍으로 작성된 엑셀을 내려받아 수정할 수 있습니다.
- **엑셀 불러오기** → **짝꿍형·짝수 열** 설정 → **멘토·멘티 배치**를 누릅니다. 현재 불러온 명렬표를 그대로 사용합니다.
- 짝을 한 묶음으로 섞고 좌우도 무작위로 정합니다. 짝 미지정 학생은 임시로 두 명씩 묶어 함께 섞습니다. 홀수로 한 명이 남으면 마지막 점유 좌석에 앉힙니다. 앞줄부터 연속해서 채우므로 중간 빈자리는 생기지 않습니다.
- **자리 바꾸기 / 천천히 공개**는 일반 배치이며 짝 정보를 적용하지 않습니다.

**천천히 공개**와 멘토·멘티 공개 중에는 원본 배경음악이 재생되고, 완료 시 효과음이 나옵니다. **소리 켜짐/꺼짐** 버튼으로 제어할 수 있습니다. 음원 출처는 [audio 기록](docs/audio/README.md)에 보관합니다.

## 프로젝트 배경

2018년 안화고등학교 재학 중, 선생님이 학생 이름을 다시 입력하지 않고 기존 엑셀 명렬표로 자리를 바꿀 수 있도록 만든 프로그램입니다. 당시에는 Electron 기반 Windows 앱이었으며, 선생님이 1년 동안 사용했다는 제작자의 회고가 있습니다.

이 저장소는 익명화한 원본과 일반 교실에서 사용할 수 있도록 개선한 웹 버전을 함께 보관합니다. 제작: **이태규** · 원본 개발: **2018년** · 웹 이식 및 개선: **2026년**

![2018년 원본 UI를 예시 이름으로 재현한 화면](docs/assets/original-ui-reproduction.png)

## 2018년 원본에서 구현한 것

- Electron 기반 Windows 앱과 40석의 고정 교실 자리표
- 엑셀 첫 시트에서 학생 이름 읽기
- Fisher-Yates 방식으로 좌석·학생 순서를 섞어 중복 없는 배치
- 한 명씩 1초 간격으로 공개하는 모드와 효과음
- 당시 반의 멘토·멘티 19쌍을 유지하는 배치
- 교탁과 좌석 순서를 뒤집는 시점 변환

원본은 이름을 `__EMPTY` 키로 읽는 특정 엑셀 형식을 전제로 했고, 파일 선택 후 배치 버튼을 눌러야 이름이 표시됐습니다. 자리 수나 교실 구조를 자동 생성하는 범용 도구는 아니었습니다.

## 이번 웹 이식에서 보완한 것

- Electron의 모듈 로딩을 브라우저용 SheetJS 0.20.3으로 교체
- 명렬표·교실 설정과 자리 조작을 분리하고 자리표를 중심으로 화면 구성
- 가변 행·열(최대 144석), 짝꿍형·개별형, 제목 편집, 전체화면, 사이드바 접기 지원
- 배치 완료 후 PDF 저장·인쇄를 위한 A4 가로 전용 출력 레이아웃
- 이름·짝 번호 열 인식, 실제 멘토·멘티 관계 보존 및 칠판 기준 앞줄 우선 배치
- 파일 크기·인원·짝 정보 오류 안내
- 모든 좌석을 초기화하도록 수정해 시점 전환 뒤 남던 이름 제거
- 순차 공개 타이머를 취소해 초기화·새 배치 이후 이전 실행이 이어지지 않도록 처리
- 실명과 당시 고정 관계를 예시 학생 이름으로 대체
- 원본의 배경음악과 완료 효과음을 순차 공개에 연결하고, 음소거·초기화 시 재생 중단 지원

따라서 공개 웹 버전은 2018년 실행 파일을 그대로 실행하는 것이 아니라, 원본 경험을 바탕으로 입력과 실행 안정성을 보완한 이식판입니다. 프로젝트 배경의 이미지는 원본 UI를 같은 시대의 로직과 예시 명렬표로 재현한 화면입니다.

## 소스와 검증

```text
docs/                GitHub Pages 웹 앱
docs/vendor/         공식 SheetJS 배포본과 Apache 2.0 라이선스
archive/2018/        익명화한 Electron 원본 소스
test/                명렬표 파싱·자리 배치 검증
```

별도 빌드나 패키지 설치 없이 정적 서버로 실행할 수 있습니다.

```sh
python3 -m http.server 8080 --directory docs
# http://localhost:8080

# Node.js 22 이상
npm test
```

현재 자동 테스트 28개로 엑셀·CSV 읽기, 동명이인 보존, 앞줄 우선 배치, 모든 지원 교실 크기의 학생 누락·중복 방지, 실제 짝 정보 검증과 인접 배치, 순차 공개·음악 중단, 시점 변환, 사이드바 전환 및 인쇄 활성화 조건을 검사합니다.

GitHub Pages는 `main` 브랜치의 `/docs` 폴더를 배포합니다. 외부 API, 계정, 서버 데이터베이스가 필요하지 않습니다.
