# Changing Sit · 자리 바꾸기

**매달 반복하던 이름 입력을, 기존 엑셀 명렬표 한 번으로.**

2018년 안화고등학교 재학 중 만든 자리바꾸기 프로그램입니다. 당시에는 Electron으로 Windows 앱을 만들었으며, 이 저장소에는 익명화한 원본과 브라우저에서 체험할 수 있는 웹 이식판을 함께 보관합니다.

제작: **이태규** · 원본 개발: **2018년** · 웹 이식: **2026년**

**[브라우저에서 사용하기 →](https://postmelee.github.io/Changing_sit/)**

![2018년 원본 UI 재현. 예시 명렬표를 사용한 브라우저 재현 화면입니다.](docs/assets/original-ui-reproduction.png)

## 왜 만들었나요?

매달 첫날의 자리바꾸기는 친한 친구와 더 가까워지거나 새로운 친구를 만나는 중요한 교실 행사였습니다. 선생님은 당시 사용하던 프로그램에 학생 이름을 다시 입력해야 했습니다.

이미 엑셀 명렬표가 있는데 같은 이름을 또 입력할 필요는 없다고 생각했습니다. 배우던 웹 기술을 교실 PC에서 쓸 수 있도록 Electron을 익혀 Windows 앱으로 만들고, 엑셀 파일에서 이름을 읽어 자리를 배치하게 했습니다. 당시 선생님은 이 도구를 1년 동안 사용했습니다. 이 사용 기간은 제작자의 회고 기록입니다.

## 웹에서 체험하기

1. [Changing Sit](https://postmelee.github.io/Changing_sit/)에서 **예시 명렬표**를 누릅니다.
2. **자리 바꾸기** 또는 **천천히 공개**를 누릅니다.
3. **시점 변환**으로 자리표의 방향을 바꿀 수 있습니다.
4. 직접 사용하려면 **엑셀 불러오기**에서 명렬표를 선택합니다.

파일은 브라우저 안에서만 읽으며 서버로 전송하거나 저장하지 않습니다. 새로고침하면 이름과 배치 결과가 사라집니다. **멘토·멘티 예시**는 학생01-학생38로 구성한 19쌍의 예시이며, 불러온 명렬표의 실제 관계를 추정하지 않습니다.

지원 형식은 `.xlsx`, `.xls`, `.csv`의 첫 번째 시트, 최대 40명·5MB입니다. 가장 명확한 형식은 아래와 같습니다.

| 번호 | 이름 |
|---|---|
| 1 | 학생01 |
| 2 | 학생02 |

[예시 엑셀 다운로드](docs/sample-roster.xlsx)

‘성명’, ‘학생명’, ‘Name’ 등의 열 제목, 제목 없는 이름 한 열, 번호+이름 형식도 지원합니다. 이름 열이 모호하면 열 제목을 ‘이름’으로 작성하도록 안내합니다. 동명이인은 각각 한 명으로 유지합니다.

## 2018년 원본에서 구현한 것

- Electron 기반 Windows 앱과 40석의 고정 교실 자리표
- 엑셀 첫 시트에서 학생 이름 읽기
- Fisher-Yates 방식으로 좌석·학생 순서를 섞어 중복 없는 배치
- 한 명씩 1초 간격으로 공개하는 모드와 효과음
- 당시 반의 멘토·멘티 19쌍을 유지하는 배치
- 교탁과 좌석 순서를 뒤집는 시점 변환

원본은 이름을 `__EMPTY` 키로 읽는 특정 엑셀 형식을 전제로 했고, 파일 선택 후 배치 버튼을 눌러야 이름이 표시됐습니다. 자리 수나 교실 구조를 자동 생성하는 범용 도구는 아니었습니다.

## 이번 웹 이식에서 보완한 것

- Electron의 모듈 로딩을 브라우저용 SheetJS 0.20.3으로 교체
- 원본 자리표의 색과 4개 분단·40석 구성을 유지하고 작은 화면에 대응
- 이름 열 인식, 파일 크기·인원·입력 오류 안내
- 모든 40석을 초기화하도록 수정해 시점 전환 뒤 남던 이름 제거
- 순차 공개 타이머를 취소해 초기화·새 배치 이후 이전 실행이 이어지지 않도록 처리
- 실명과 당시 고정 관계를 예시 학생 이름으로 대체
- 효과음 파일은 웹 이식 및 공개 아카이브에서 제외

따라서 공개 웹 버전은 2018년 실행 파일을 그대로 실행하는 것이 아니라, 원본 경험을 바탕으로 입력과 실행 안정성을 보완한 이식판입니다. 위 이미지는 원본 UI를 같은 시대의 로직과 예시 명렬표로 재현한 화면입니다.

## 소스와 검증

```text
docs/                GitHub Pages 웹 앱
docs/vendor/         공식 SheetJS 배포본과 Apache 2.0 라이선스
archive/2018/        익명화한 Electron 원본 소스
test/                명렬표 파싱·자리 배치 검증
```

별도 빌드나 패키지 설치 없이 정적 서버로 실행할 수 있습니다.

```sh
python3 -m http.server 8080 --directory docs
# http://localhost:8080

# Node.js 22 이상
npm test
```

테스트는 실제 엑셀 변환, 원본 빈 헤더 형식, 제목이 있는 명렬표, 첫 학생·동명이인 보존, 인원 제한, 이름의 누락·중복 없는 배치를 검사합니다.

GitHub Pages는 `main` 브랜치의 `/docs` 폴더를 배포합니다. 외부 API, 계정, 서버 데이터베이스가 필요하지 않습니다.
